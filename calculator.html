Formül Hesaplayıcı (Statik Referans)

Stress Definition

σ = F / A

Strain Definition

ε = ΔL / L₀

Young's Modulus (Hooke's Law)

E = σ / ε

Poisson's Ratio

ν = -ε_trans / ε_axial

Shear Modulus

G = τ / γ

Bulk Modulus

K = P / (ΔV/V)

Relation: E, G, ν

E = 2G(1 + ν)

Relation: E, K, ν

E = 3K(1 - 2ν)

Re-entrant Poisson's Ratio (ν_yx)

ν_yx = (h/l + sinθ)sinθ / cos²θ

Re-entrant Young's Modulus (E_y)

E_y = E_s(t/l)³ cosθ / [(h/l + sinθ)sin²θ]
